# Every direct dependency is pinned with `==`. The pins are the versions the
# production stack is actually running (deploy box, verified green by the full
# pytest gate on 2026-09-20), so CI tests what prod runs and the deployer's
# pip step on a requirements change stays a no-op. Transitive dependencies
# still float -- this buys reproducibility of the surface we import, not a
# full lockfile. Bump these through the Dependabot PRs (.github/dependabot.yml)
# so every bump goes through the gate rather than arriving unannounced on the
# next fresh install.
